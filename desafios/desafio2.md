# Contagem Recursiva de Elementos

Uma biblioteca está organizando caixas para uma exposição. Cada caixa contém uma lista de objetos, como livros, mapas ou fotografias, e a equipe precisa registrar quantos objetos há em cada lista. O relatório também informa a cor das caixas, o nome da pessoa responsável e a sala onde cada caixa ficará.

Crie uma função `contarElementos(lista)` que retorne a quantidade de elementos da lista. A função deve funcionar para a lista vazia e para listas com qualquer quantidade de elementos, sem receber previamente essa quantidade.
## Prompts cognitivos

- O que deve acontecer quando a lista estiver vazia?
- Descreva a solução em texto antes de construir o grafo.
- Que parte da solução se repete a cada etapa?
- Como você verificaria a solução com uma lista vazia, uma lista unitária e
  uma lista com vários elementos?
## Self-explanation

- Como sua solução reduz o problema original?
- Qual é a relação entre o primeiro elemento, o restante e o resultado?
- O que permaneceu igual em cada aplicação da mesma estratégia?
- Que outra operação sobre listas poderia usar uma decomposição semelhante?
