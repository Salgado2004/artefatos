# Artefatos e desafios de pesquisa para o estudo da abstração e pensamento computacional por meio da linguagem visual Pandora.
Este repositório reúne os artefatos produzidos durante a pesquisa sobre abstração, pensamento computacional e programação funcional desenvolvida a partir da linguagem visual Pandora.

## Objetivo
O projeto investiga como estudantes iniciantes manifestam processos de abstração e raciocínio lógico-algorítmico ao resolver desafios baseados em programação funcional.

A proposta está fundamentada em:

- Programação Funcional e abordagens _Functional First_;
- Linguagem visual Pandora;
- Processos cognitivos de abstração;
- Estudos sobre dificuldades no aprendizado de programação.

## Estrutura do Repositório

`/desafios` - Contém os enunciados utilizados no estudo.

Os desafios foram planejados para estimular:
- filtragem de informações;
- identificação de similaridades;
- mapeamento estrutural;
- decomposição;
- generalização;
- reutilização;
- composição funcional.

`/solucoes` - Contém propostas de resolução e comentários sobre os resultados esperados de cada desafio.

Essas soluções não representam a única resposta correta, mas funcionam como referência para análise dos processos cognitivos investigados.

## Sequência de Desafios
| Desafio	                                | Foco Principal	                    | 
| ------------------------------------------| --------------------------------------|
| 1. Padrões em uma Sequência de Resultados | Filtragem e reconhecimento de padrões |
| 2. Contagem Recursiva de Elementos	    | Mapeamento estrutural                 |
| 3. Caminhos em uma Escadaria	            | Decomposição recursiva	            |
| 4. Identificação de Potências de Dois	    | Modelagem computacional	            |
| 5. Generalização de Potências	            | Generalização	                        |
| 6. Remoção Seletiva de Elementos	        | Reutilização de estratégias	        |
| 7. Criando um Filtro Reutilizável	        | Abstração reutilizável	            |
| 8. Separação em Duas Listas	            | Composição de abstrações              |

## Relação com a Pesquisa
Os desafios não foram organizados apenas por dificuldade técnica. A sequência foi projetada para estimular progressivamente diferentes manifestações da abstração, permitindo observar evidências qualitativas dos processos cognitivos envolvidos na resolução de problemas computacionais.
