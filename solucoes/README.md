# Soluções
Este diretório contém as soluções propostas para cada um dos desafios.

Essas soluções não representam a única resposta correta, mas funcionam como referência para análise dos processos cognitivos investigados.

Para cada desafio, há um arquivo de solução correspondente, que inclui:
- `README.md`: Contém a descrição do desafio, a solução proposta e comentários sobre os resultados esperados.
- `Arquivos .png`: Contém imagens ilustrativas da solução proposta.
- `Arquivos .json`: Contém representações serializadas dos grafos utilizados na solução, compatíveis com a IDE Pandora.
